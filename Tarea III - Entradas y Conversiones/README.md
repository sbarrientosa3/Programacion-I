Breve explicación del programa:
  Creado con el propósito de simular un sistema básico de facturación. 
  La tarea principal es solicitar el nombre completo del cliente al usuario a través de getline(), así como el precio y la cantidad de un artículo. 
  Se calcula el subtotal, el impuesto IVA del 12% y el total utilizando operaciones aritméticas.
  Se aplicaron las funciones fixed y setprecision de la biblioteca iomanip, lo que permite una presentación de datos ordenada y con formato de dos      dígitos decimales.
